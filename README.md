## 중간고사 추가 기능: 완료한 설정 다시 확인

훈련 설정을 완료한 뒤 `완료한 설정 확인하기` 버튼을 누르면 내가 정한 훈련 제목, 시간, 질의응답 설정을 완료 화면에서 다시 볼 수 있습니다. 별도의 입력은 필요하지 않으며, 다시 누르면 내용이 접힙니다.

### 사용자 행동과 화면 반응

- 사용자 행동: 훈련 제목과 조건을 정하고 설정을 완료한 뒤 `완료한 설정 확인하기`를 누릅니다.
- 조건: 훈련 설정 완료 단계에 도달했는가? 제목은 앞 단계에서 비어 있지 않은지 확인하고, 제목과 조건은 완료 전에 저장됩니다.
- 성공 반응: 완료 화면에 설정한 제목, 시간, 질의응답 포함 여부와 질문 수가 표시됩니다. 질의응답을 선택하지 않았다면 `미포함`으로 나타납니다.
- 다른 상태: `설정 내용 숨기기`를 누르면 요약이 접히고 완료 화면으로 돌아갑니다. 다시 확인하거나 `다시 설정하기`로 새 설정을 시작할 수 있습니다.
- 다음 행동: 설정 요약을 다시 열어 확인하거나 다시 설정을 시작합니다. 다시 설정하면 입력값과 요약 표시 상태가 초기화됩니다.

### 직접 테스트 결과

- 정상 경로: 제목 `목 어깨 스트레칭`, 시간 `10분`, 질의응답 `3개 포함`으로 설정을 완료했습니다. 확인 버튼을 눌렀을 때 세 값이 모두 표시되었습니다.
- 숨김·재확인: 설정 내용을 숨긴 뒤 다시 열어 같은 설정값이 표시되는 것을 확인했습니다.
- 다시 설정: `다시 설정하기`를 눌렀을 때 확인 영역이 닫히고 새 제목 입력 단계로 이동했습니다.
- 모바일 확인: 브라우저 너비 390px에서 요약 패널과 버튼이 화면 안에 표시되고 가로 넘침이 없었습니다.
