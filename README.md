## 4주차 반응형 수정

### 확인할 문제
작은 화면에서 메뉴, 기능 카드, 이메일 폼이 좁아 보였다.

### 수정한 내용
- viewport 메타 태그를 추가했다.
- 콘텐츠에 width와 max-width를 함께 사용했다.
- 기능 카드 목록을 반응형 Grid로 변경했다.
- 768px 이하에서 메뉴, 카드, 폼을 한 열로 구성했다.

### 확인할 화면 너비
1100px / 769px / 768px / 390px


## 5주차 JavaScript 인터렉션 추가

### 확인할 문제
이메일 신청 후 완료 여부가 명확하게 표시되지 않았다.

### 수정한 내용
- 이메일이 비어 있으면 안내 문구를 표시하고 입력창에 포커스한다.
- 이메일 신청이 완료되면 성공 메시지를 표시하고 버튼을 비활성화한다.
- 성공 메시지 스타일을 모든 화면 너비에서 적용되도록 수정했다.

### 확인할 동작
빈 이메일 제출 / 올바른 이메일 제출


## 6주차 JavaScript 이벤트와 탭 인터랙션

### 확인할 문제
기능별 안내를 한 화면에서 확인하기 어렵고, 훈련을 시작하기 전에 필요한 설정과 동의 여부를 확인할 수 없었다.

### 수정한 내용
- 탭을 선택하면 해당 기능 패널만 표시하도록 구현했다.
- 다크 테마 전환 버튼을 추가했다.
- 사용자 이름 입력 길이를 최대 10자로 제한하고 현재 글자 수를 표시한다.
- 영상 활용 동의 여부에 따라 훈련 시작 버튼을 활성화하고 안내 문구를 변경한다.

### 확인할 동작
기능 탭 전환 / 다크·라이트 테마 전환 / 사용자 이름 글자 수 표시 / 동의 전후 훈련 시작 버튼 상태
