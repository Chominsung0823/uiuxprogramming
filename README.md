# 12주차 과업 QA와 작성 상태 복구

## 서비스와 개선 목적

**올바른 자세 가이드**는 바른 자세를 연습하고, 맞춤 훈련을 설정하며, 연습 기록과 훈련 소식 신청을 관리하는 웹 프로토타입입니다.

대표 과업을 수행하다 새로고침해도 작성 중인 훈련 설정을 이어갈 수 있도록 현재 탭의 `sessionStorage`에 임시 보관합니다. 훈련 제목, 사용자 이름, 영상 활용 동의 선택, 훈련 시간, 집중 연습 항목과 현재 단계가 복구됩니다. 저장된 설정을 완료하거나 다시 설정하기를 누르면 이전 임시 내용은 삭제됩니다. 이 페이지는 실제 영상을 녹화하지 않습니다.

## 1. 과업 기반 QA

### 대표 과업

- **목표:** 점심시간에 할 자세 훈련을 설정하고 연습 목록에 저장한다.
- **상황:** 직장인이 잠시 자리를 비우기 전에 훈련 제목과 조건을 정하던 중 페이지를 새로고침한다.
- **시작 조건:** 웹페이지를 열고 훈련 설정을 시작할 수 있는 상태이며, 이전 작성 내용이나 저장된 테스트 데이터가 없는 브라우저 탭.
- **행동:** 영상 활용 안내를 확인하고 훈련 설정을 연다. `점심시간 자세 연습`, 10분, `화면 높이와 시선`을 선택하고 최종 저장 전 확인 단계에서 새로고침한다. 복구된 내용을 확인한 뒤 설정을 완료하고, 다시 설정하기를 눌러 새 설정을 시작한다.
- **기대 결과:** 새로고침 뒤 확인 단계와 입력·선택값이 돌아오고, 설정 완료 시 연습 목록에 저장되며 임시 내용이 지워진다. 다시 설정하기 후에는 이전 제목·선택값이 남지 않는다.

### 구현 전 QA

- **실행:** 2026-11-23, 통합 브라우저에서 대표 과업을 직접 수행하고 최종 저장 전에 새로고침.
- **실제 결과:** 새로고침 후 훈련 설정 영역이 닫혔고 제목은 빈 값, 훈련 시간은 기본값으로 돌아갔으며 진행 단계도 복구되지 않았다.
- **예상 사용자 영향:** 작성한 내용을 다시 입력해야 하므로 시간과 노력이 낭비된다. 중단된 과업을 포기하거나 잘못된 설정을 저장할 수 있다.
- **조치:** 현재 탭에 작성 상태를 임시 저장하고 새로고침 시 화면·안내·값을 복구하도록 구현했다.

### 구현 후 재검증

- **실행:** 2026-11-23, 통합 브라우저에서 같은 훈련 내용을 작성하고 정보 단계, 조건 단계, 확인 단계 각각에서 새로고침을 확인했다.
- **실제 결과:** 세 단계 모두 작성 중이던 화면으로 돌아왔다. 확인 단계에서는 제목 `점심시간 자세 연습`, 10분, `화면 높이와 시선` 및 복구 안내가 표시됐다. 영상 활용 동의 선택도 같은 탭에서 복구됐다.
- **완료·초기화 결과:** 설정 완료 후 맞춤 연습이 목록에 추가됐고 임시 저장 키가 삭제됐다. 다시 설정하기 후 제목이 빈 값으로 초기화되고 이전 임시 저장 키도 삭제됐다.
- **재검증 영향:** 과업을 처음부터 반복하지 않고 이어서 완료할 수 있었다. 다시 설정하기는 이전 과업 값이 아니라 기본값으로 시작했다.

- 참여자 조건(가상): P01, 평소 데스크톱 웹 서비스를 사용하고, 업무 중 자세 관리에 관심이 있는 직장인
- 방법: 진행자가 과업 목표와 상황만 전달. 클릭 순서를 알려주지 않고 행동·발화를 관찰. T1 중간에 진행자가 페이지를 새로고침한 뒤 “하던 일을 계속해 주세요.”라고 안내. 과업 완료 후 같은 과업을 다시 수행하게 함.
- 환경: 2026-11-23, 실내 테스트 공간, 노트북·Edge, 총 15분
- 개인정보/촬영: 실사용 연락처 대신 테스트용 이메일을 사용하는 것으로 설정. 촬영 미동의.

#### 과업 T1 — 대표 과업

- 참여자에게 읽을 문장(목표·상황): “점심시간에 짧게 자세를 연습하고 싶습니다. 본인에게 맞는 훈련을 설정해 저장해 주세요.”
- 시작 화면·입력값: 처음 방문한 홈 화면, 기존 작성 내용과 사용자 기록 없음. 진행자는 참여자가 훈련 제목과 조건을 일부 작성한 뒤 새로고침하고 “하던 일을 계속해 주세요.”라고만 안내.
- 완료 조건: 작성 중이던 화면과 값으로 돌아와 설정을 끝내고, 완료한 훈련이 연습 목록에서 확인됨. 다시 설정하기를 누른 뒤 이전 작성 내용이 남지 않음을 확인.
- 제한 시간: 4분.

#### 과업 T2 — 다른 경로 과업

- 참여자에게 읽을 문장(목표·상황): “자세 훈련 소식을 이메일로 받고 싶습니다. 관심 있는 주제의 소식 신청을 마쳐 주세요.”
- 시작 화면·입력값: 홈 화면의 초기 상태. 테스트용 이름과 `p01@example.com`을 사용.
- 완료 조건: 필수 입력값과 관심 주제를 제출하고 신청 완료 안내를 확인.
