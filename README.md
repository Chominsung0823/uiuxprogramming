# 12주차 UI 컴포넌트 구현 — 올바른 자세 가이드

올바른 자세를 배우고 연습하며, 맞춤 훈련을 설정하고 자세 연습 기록을 관리하는 서비스입니다. 기존 서비스 화면에 재사용할 수 있는 탭, 모달, 아코디언 UI를 적용했습니다.

## 구현한 UI 컴포넌트

### 1. 탭 — 훈련 기능

- **사용 목적:** 단계별 연습, 자세 유지 기록, 자세 유지 피드백을 한 영역에서 나누어 보여줍니다.
- **동작 방법:** 탭을 클릭하거나 탭에 초점을 둔 상태에서 좌우 방향키를 누르면 선택 탭과 내용이 바뀝니다. Home/End 키로 첫 탭과 마지막 탭으로 이동할 수도 있습니다.

### 2. 모달 — 영상 활용 안내

- **사용 목적:** 훈련 설정을 시작하기 전에 영상 활용과 녹화 여부를 안내하고 동의를 확인합니다.
- **동작 방법:** 영상 활용에 동의한 뒤 훈련 설정 시작 버튼을 누르면 안내 모달이 열립니다. 돌아가기 버튼이나 Escape 키로 닫으면 동의가 해제되고, 동의하고 설정 시작하기를 선택하면 훈련 설정 단계가 열립니다. 이 페이지에서는 실제 녹화를 시작하지 않습니다.

### 3. 아코디언 — 자세 연습 FAQ 및 상세 정보

- **사용 목적:** 자주 묻는 질문과 자세 연습의 세부 설명을 필요할 때 펼쳐 화면을 간결하게 유지합니다. 완료한 훈련 설정도 같은 펼침/접힘 동작으로 다시 확인할 수 있습니다.
- **동작 방법:** 질문이나 상세 보기 버튼을 클릭하면 답변 또는 설명이 열리고, 다시 누르면 닫힙니다. 버튼 이름과 펼침 상태가 함께 바뀝니다.

## 재사용 및 접근성

- 아코디언의 공통 펼침/접힘 동작은 `bindDisclosure`와 `setDisclosureState` 함수로 처리합니다.
- 탭, 모달, 아코디언은 실제 버튼을 사용해 Tab 이동 후 Enter/Space로 조작할 수 있으며, 초점 표시를 제공합니다.
- 탭에는 `role="tab"`과 `aria-selected`를, 아코디언 버튼에는 `aria-expanded`와 `aria-controls`를 적용했습니다. 모달에는 제목·설명 연결과 기본 키보드 초점 처리를 적용했습니다.
- 훈련 목록 필터는 선택 상태를 버튼 스타일과 `aria-pressed`로 함께 표시합니다.

## 모바일 및 예외 테스트 결과

브라우저의 반응형 뷰포트에서 320px, 390px, 768px, 1280px 너비를 확인했습니다. 각 크기에서 문서의 콘텐츠 너비가 뷰포트 너비를 넘지 않아 가로 스크롤이 생기지 않았습니다. 모바일 브라우저 실제 기기와 스크린 리더 조합은 별도 확인이 필요합니다.

- FAQ 질문을 열고 다시 닫으면 `aria-expanded`와 답변 표시가 함께 바뀌는 것을 확인했습니다.
- 탭을 선택하면 해당 패널만 표시되고 선택 상태가 이동하는 것을 확인했습니다. 키보드 좌우 방향키로 탭을 이동하는 동작도 확인했습니다.
- 동의 후 훈련 안내 모달을 열고 돌아가기를 선택하면 모달이 닫히고 동의가 해제되는 것을 확인했습니다. Escape 키로 닫을 때도 동의가 해제됩니다.
- 훈련 제목을 입력하지 않고 다음 단계로 진행할 때 단계 이동이 막히고, 오류 문구와 입력란 초점이 표시되는 것을 확인했습니다.
- 연습 목록의 상세 보기 버튼으로 설명을 펼치고 다시 접을 수 있는 것을 확인했습니다.
