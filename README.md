# 11주차 웹 접근성 개선 — 올바른 자세 가이드

바른 자세를 배우고 연습하며, 맞춤 훈련을 설정하고 자세 연습 기록을 관리할 수 있는 서비스입니다.

## 접근성 개선 내용

- 색상과 상태: 반투명 녹색 제목·버튼 및 색으로만 구분하던 상태 → 대비가 높은 색으로 조정하고, 필터 체크 표시·상태 문구·`aria-pressed`를 함께 제공
- 이미지와 이름: 이미지의 일반적인 대체 텍스트와 연결 오류가 있던 안내 창 → 자세 비교 그림을 설명하는 대체 텍스트와 올바른 `aria-labelledby` 적용
- 키보드와 초점: 초점 표시와 탭 이동이 충분하지 않았던 기능 영역 → 건너뛰기 링크·전체 초점 표시·방향키/Home/End 탭 이동·단계 전환 초점 제공
- 선택과 오류 안내: 색상 위주의 진행 표시와 막연한 오류 안내 → 밑줄 및 `aria-current`로 현재 단계를 알리고, 구체적인 오류 문구와 `aria-invalid`를 제공

## 모바일 및 예외 테스트 결과

브라우저 모바일 뷰포트(390 × 844)와 데스크톱 뷰포트(1280 × 900), 키보드 입력으로 확인했습니다.

- 모바일에서 메뉴가 처음에는 접혀 있고 Enter로 열리며, 메뉴 항목 선택 후 다시 접히는 것을 확인했습니다.
- 모바일 화면에서 가로 넘침이 없는 것을 확인했습니다.
- 훈련 설정의 `1. 정보`, `2. 조건`, `3. 확인` 표시가 320·390·768·1280px 화면에서 겹치거나 가로로 넘치지 않는 것을 확인했습니다.
- 대표 색상 대비를 확인했습니다. 일반 화면은 제목 6.45:1, 본문 6.99:1, 버튼 6.61:1이며 다크 화면은 제목 10.85:1, 본문 9.05:1입니다.
- Tab으로 기능 탭에 진입하고 방향키, Home, End로 탭을 이동한 뒤 패널에도 초점이 이동하는 것을 확인했습니다.
- Tab으로 건너뛰기 링크에 초점이 보이고, Enter를 누르면 본문으로 이동하는 것을 확인했습니다.
- 키보드로 훈련 설정을 진행하고 단계별 제목으로 초점이 이동하는 것을 확인했습니다. 필수 제목을 비워 진행할 때는 오류 안내와 함께 입력란으로 초점이 이동합니다.
- 훈련 조건에서 집중 연습 항목을 선택하면 확인 단계와 완료한 맞춤 훈련 기록에 선택 내용이 반영되는 것을 확인합니다.
- 필수 입력이 빈 구독 폼을 제출하면 오류 문구와 `aria-invalid`가 설정되고 이름 입력으로 초점이 이동하는 것을 확인했습니다.
- 연습 목록 저장 데이터가 잘못된 JSON인 경우 기본 목록과 복구 안내가 표시되는 것을 확인했습니다.

실제 휴대전화와 보조 기술 조합의 터치·스크린 리더 확인은 배포 후 별도 점검이 필요합니다.
