# 올바른 자세 가이드

바른 자세 연습, 훈련 설정과 훈련 소식 신청을 제공하는 서비스입니다. 훈련 항목과 신청 정보는 서버 대신 브라우저 `localStorage`에 저장합니다.

## 이번 주 추가·수정한 기능

- 주요 메뉴를 목록 구조로 구성하고 현재 위치를 `aria-current`와 시각적 표시로 안내
- 모바일 화면에서 메뉴 열기·닫기 버튼, 표시 상태, 버튼 문구와 `aria-expanded`를 동기화
- 자세 연습 목록에 전체·연습 전·연습 완료 필터와 표시 항목 수, 빈 결과 안내 추가
- 항목 상세 보기와 완료 상태 저장을 지원하고, 완료한 맞춤 훈련 설정을 목록에 기록
- 기존 탭, 단계별 훈련 설정, 구독 폼의 입력 검증·저장 기능 유지

## 메뉴별 목적지

- 서비스 소개: 자세 가이드와 서비스 설명
- 훈련 기능: 단계별 연습·기록·피드백 탭
- 이용 방법: 서비스 이용 순서
- 훈련 시작: 사용자 정보와 동의 확인, 훈련 설정 진입
- 훈련 기록: 자세 연습 항목과 상태 필터
- 훈련 소식 신청: 관심 주제 및 선택 상담 신청 폼

현재 메뉴는 해시 경로를 기준으로 표시하며, 새로고침과 브라우저 뒤로·앞으로 이동에도 갱신됩니다.

## 필터 기준 및 확인 순서

필터는 진행 상태 기준이며 `전체`, `연습 전`, `연습 완료` 세 가지입니다. 완료한 맞춤 훈련도 목록에 자동으로 추가됩니다.

1. PC와 모바일 화면에서 메뉴를 열어 각 목적지로 이동합니다. 모바일에서는 목적지를 선택한 뒤 메뉴가 닫히는지 확인합니다.
2. `훈련 시작`에서 사용자 이름을 입력하고 영상 활용에 동의한 뒤 훈련 설정을 완료합니다.
3. `훈련 기록`으로 이동해 완료한 맞춤 훈련이 추가되고 항목 상세 보기와 완료 상태 변경이 되는지 확인합니다.
4. `전체`, `연습 전`, `연습 완료`를 차례로 선택해 버튼 선택 표시, `aria-pressed`, 목록 내용, 항목 수 안내를 확인합니다.
5. 메뉴를 이동한 뒤 새로고침하거나 브라우저 뒤로 가기를 눌러 현재 메뉴 표시를 확인합니다.
6. `훈련 소식 신청`에서 필수 항목과 선택 상담 정보를 입력하고 제출·저장·초기화 동작을 확인합니다.

## 구독 폼 입력 조건

- 이름: 필수, 공백 제외 2~10자
- 이메일: 필수, 이메일 형식
- 관심 있는 훈련 주제: 필수, 목록에서 한 가지 선택
- 상담 안내를 선택한 경우: 휴대전화와 연락 가능 시간 필수
- 휴대전화: `010-1234-5678`과 같은 국내 휴대전화 형식

## 구현 위치

- 메뉴, 훈련 설정, 목록과 구독 폼 마크업: `index.html`
- 메뉴·필터·목록 저장 및 구독 폼 동작: `script.js`
- 반응형 메뉴와 목록·상태별 스타일: `style.css`
- 브라우저 저장 실패 시 목록 또는 폼에 안내를 표시하며, 입력 내용은 유지합니다.
