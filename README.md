# 올바른 자세 가이드: 훈련 소식 신청 폼

자세 교정 훈련 소식을 신청하는 폼을 추가했습니다. 이름, 이메일, 관심 주제를 입력하고 선택적으로 상담 안내를 요청할 수 있습니다. 서버 대신 브라우저 `localStorage`에 신청 정보를 저장합니다.

## 추가·수정한 기능

- 이름, 이메일, 관심 주제 입력과 항목별 도움말 및 label 연결
- 입력 중 이름 글자 수와 최소 글자 조건 표시
- 상담 안내 체크 시 전화번호와 연락 가능 시간 입력 영역 표시
- 조건부 영역을 닫으면 입력 요소를 `disabled` 처리하고, 다시 열면 활성화
- 제출 전 필수 항목, 이메일 형식, 이름 글자 수, 전화번호 형식 검증
- 오류 문구와 `aria-invalid` 상태를 입력 중 갱신하고, 제출 시 첫 오류 항목으로 이동
- 제출 중 버튼을 비활성화하고 진행 문구 표시
- 성공 시 완료 안내 및 중복 신청 방지, `다시 작성하기`로 폼과 안내 상태 초기화
- 브라우저 저장 실패 시 입력 내용을 보존하고 재시도 버튼 제공

## 입력 조건

- 이름: 필수, 공백 제외 2~10자
- 이메일: 필수, 이메일 형식
- 관심 있는 훈련 주제: 필수, 목록에서 한 가지 선택
- 상담 안내를 선택한 경우: 휴대전화와 연락 가능 시간 필수
- 휴대전화: `010-1234-5678`과 같은 국내 휴대전화 형식

## 확인 순서

1. 모든 입력을 비운 채 신청해 필수 오류 문구와 첫 수정 항목 포커스를 확인합니다.
2. 한 글자 이름과 잘못된 이메일을 입력합니다. 조건 미충족 안내를 확인한 뒤 올바른 값으로 고쳐 오류가 사라지는지 확인합니다.
3. 상담 안내를 선택해 전화번호와 시간 영역이 표시되고 활성화되는지 확인합니다. 상담 선택을 해제하면 영역이 숨겨지고 입력 요소가 비활성화됩니다.
4. 잘못된 전화번호를 제출해 오류를 확인하고, 올바른 번호로 수정합니다.
5. 정상 제출 시 진행 중 버튼이 비활성화되고 완료 안내가 나타나는지 확인합니다.
6. `다시 작성하기`를 눌러 입력값, 오류·완료 안내, 버튼 상태, 상담 영역이 초기화되는지 확인합니다.
7. 저장 실패는 브라우저 저장 API가 예외를 던지는 상황으로 확인합니다. 실패 안내가 표시되고 기존 입력값이 남으며 버튼으로 다시 시도할 수 있습니다.

## 구현 위치

- 폼 마크업과 입력 도움말: `index.html`의 `#subscribe` 섹션
- 입력 검증, 조건부 영역, 제출·저장·초기화: `script.js`의 구독 폼 이벤트 처리
- 폼 레이아웃과 상태별 스타일: `style.css`의 `#subscribe-form` 및 `#subscribeMessage` 규칙
- 저장 실패 처리는 `script.js`의 `localStorage` 저장 `try/catch`에서 처리합니다. 실패해도 폼을 비우지 않고 제출 버튼을 다시 활성화합니다.
